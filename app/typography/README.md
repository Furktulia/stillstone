# Display lettering

Libre Baskerville, normal variable font, bundled unchanged under SIL OFL 1.1.
Source: https://github.com/google/fonts/blob/main/ofl/librebaskerville/LibreBaskerville%5Bwght%5D.ttf
Git blob SHA: eae4eba83203138da3a3a7603b598b7ebc5a5238

The original is text-encoded for IDE-safe import. DecodeDisplayFont emits a normal
Android res/font TTF during the build; builds and runtime require no network.
Copyright and license are packaged at assets/licenses/LibreBaskerville-OFL.txt.
Used for headings, level numbers and stone button labels; small utility text
retains the readable system sans serif. Chosen to match the mock's broad,
bracketed serif lettering; the generated mock has no identifiable font metadata.
